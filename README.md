# Business Management System — Next.js

A mentorship/preparation project demonstrating a small ERP-style business application.

## Stack
- Next.js
- TypeScript
- MongoDB
- Mongoose
- Tailwind CSS

## Planned modules
- Authentication
- Role-based access
- Products & inventory
- Customers
- Orders
- Dashboard

This starter contains the project structure and planning files so you can implement each module progressively.
